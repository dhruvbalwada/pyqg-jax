Next-Order (QG+1) Model

A next-order-in-Rossby (QG+1) balanced model.

This model extends the continuous-stratification quasigeostrophic model to next order in the Rossby number following Dù, Smith & Bühler (2024) (clean-room from arXiv:2408.03422). The leading-order dynamics are ordinary continuous QG; the next-order corrections add ageostrophic velocities, a self-consistent vertical velocity, and the cyclone/anticyclone asymmetry that leading-order QG cannot represent.

The leading-order inversion is inherited verbatim from ContinuousQGModel; the next-order corrections are computed by pyqg_jax._qgplus1.

class pyqg_jax.qgplus1_model.QGPlus1Model(*, nx=64, ny=None, nz=24, L=1000000.0, W=None, H=4000.0, f=0.0001, g=9.81, beta=0.0, N2=0.0001, U=None, rek=0.0, filterfac=23.6, precision=Precision.SINGLE)[source]

Next-order-in-Rossby (QG+1) balanced model.

Same construction and prognostic state as ContinuousQGModel (interior potential vorticity plus surface/bottom buoyancy on a Chebyshev vertical grid), but the diagnostics and (optionally) the dynamics carry the first-order Rossby corrections of Dù, Smith & Bühler (2024).

The background mean state is the Eady profile U = Lambda * z; the shear \(\Lambda\) is read from the supplied U. A uniform \(N^2\) is assumed (the next-order operator \(\mathcal{L} = N^2\nabla^2 + f^2\partial_{zz}\) reduces to the inherited inversion operator only for constant \(N^2\)).

Added in version 0.9.0.

See also

get_updates(state)[source]

Compute the QG+1 time-stepping tendency.

The prognostic potential vorticity is advected by the full next-order three-dimensional velocity (Eq. 29a of Dù, Smith & Bühler 2024), including the vertical advection \(w\,q_z\) on the interior, while the surface/bottom buoyancy is advected by the full horizontal velocity. The background mean-state terms (Ubg and ikQy) are inherited unchanged from the leading-order model.

Parameters:

state (PseudoSpectralState) – The state to be time stepped.

Returns:

A state object whose qh holds the tendency update.

stability_analysis()[source]

Linear stability analysis of the background state.

Solves, at every wavenumber, the eigenvalue problem for normal modes \(\hat\theta \propto e^{-\mathrm{i}\omega t}\) of the linearized dynamics,

\[k\,(\mathsf{U} + \mathsf{Q}_y\,\mathsf{a})\,\tilde\theta = \omega\,\tilde\theta,\]

where \(\mathsf{U} = \mathrm{diag}(\mathtt{Ubg})\), \(\mathsf{Q}_y = \mathrm{diag}(\mathtt{Qy})\), and \(\mathsf{a}\) is the model’s inversion matrix (\(\hat\psi = \mathsf{a}\,\hat q\)). The growth rate at each wavenumber is \(\mathrm{Im}(\omega)\).

Added in version 0.9.0.

Returns:

  • omega (jax.Array) – The eigenvalue with the largest growth rate (imaginary part) at each wavenumber, shape (nl, nk). The growth rate is omega.imag and the phase speed is omega.real / k.

  • evec (jax.Array) – The corresponding eigenvector (the vertical structure of the most unstable mode) at each wavenumber, shape (nz, nl, nk).

Note

The eigenvalue problem is solved on the host with NumPy, so this is a host-side diagnostic (not differentiable or jit-compatible). It works regardless of the active JAX platform.

property z[source]

The vertical collocation points (descending from 0 to -H).
